GoldSrc Engine
```
Late 90s Game engine.
Used in Counter Strike 1.x,
Half- Life, etc.
Based on the one used on Quake from Id Software.
It supports up to 1200 simultaneous entities,
up to 900 of them being interactive and controllable via netcore shared between client and server.
It uses very clever math to execute certain tasks efficiently,
but it comes at the expense of polish and stability.
The GoldSrc Engine also cannot speak,
eat, sleep, defecate
or any action usually performed by a living system.
It is literally a game engine.

Try not to abuse the create entity command too much.
Oh.
And make sure to give it a model upon spawning one before whining in the forums
```
